# AdvanXe360 1.0.0 con Kinect (pre-release)

La misma **AdvanXe360 1.0.0** con soporte para el **Kinect**. Es experimental: la versión oficial es la que no lo tiene ([v1.0.0](../../releases/tag/v1.0.0)).

## Qué agrega

- **Control con la mano en la Biblioteca**: levanta la mano para mover el cursor; déjala quieta sobre un juego para abrirlo; desliza rápido para cambiar de página o de consola.
- **Game Boy Camera** con la cámara del Kinect.
- Se activa en **Ajustes → Kinect** (viene apagado).

## Requisitos

- Un Kinect conectado.
- Los archivos **Database** del XDK (`Database.xmplr`, `NuiIdentity.bin.be`, etc.) **junto a `default.xex`**. Sin ellos el Kinect no arranca (el log dice *E_NUI_DATABASE_NOT_FOUND*).

## Instalación

Descarga **`AdvanXe360-v1.0.0-kinect.zip`**, copia la carpeta a la consola, agrega los archivos Database y abre `default.xex` desde Aurora. Todo lo demás es igual que en la versión oficial: lee sus notas para ver lo nuevo de la 1.0.0.

---

*English:* AdvanXe360 1.0.0 with **Kinect** support (experimental pre-release): hand control in the Library and the Game Boy Camera using the Kinect's camera. Needs a Kinect and the XDK's Database files next to `default.xex`. The official release is the one without Kinect.
